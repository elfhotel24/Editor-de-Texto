# 📝 Editor de Texto

Editor de texto de escritorio desarrollado en **C# con Windows Forms**, similar al Bloc de Notas, pero con funcionalidades adicionales de personalización como **cambio de tamaño, tipo de letra y color del texto**.

---

## 📋 Descripción

Aplicación de escritorio que permite crear, abrir, editar y guardar archivos de texto con formato personalizado. A diferencia de un editor básico, ofrece control total sobre la apariencia del texto (fuente, tamaño, color), brindando una experiencia más flexible para el usuario.

## 🚀 Instalación y ejecución

### Requisitos previos

- Visual Studio 2019 o superior
- .NET Framework 4.7.2+ o .NET 6+ con soporte para Windows Forms

### Pasos

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/elfhotel24/Editor-de-Texto.git
Abre la solución:
Abre EditorDeTexto.sln con Visual Studio.

Compila y ejecuta:
Presiona F5 en Visual Studio o haz clic en "Iniciar".

⚙️ Funcionalidades
✅ Nuevo archivo — Crear un documento nuevo.

✅ Abrir — Cargar archivos de texto desde el disco.

✅ Guardar / Guardar como — Almacenar cambios en el archivo actual o en uno nuevo.

✅ Cambiar tipo de letra — Seleccionar entre distintas fuentes tipográficas.

✅ Cambiar tamaño de letra — Ajustar el tamaño del texto.

✅ Cambiar color del texto — Personalizar el color de la tipografía.

✅ Cortar, copiar y pegar — Funciones básicas de edición.
